# GHD Score — 国旗护卫队积分管理与统计工具

面向高校/社团“国旗护卫队”的单机版积分管理与统计工具。开箱即用、无须部署，
核心围绕**项目工程制**（借鉴 Premiere Pro 工程设计）与**本地 Excel 表格双向绑定**展开。

- 技术栈：Python + Flet（Material Design 3，深色主题） + pandas + openpyxl
- 持久化：项目工程文件（`.ghd.json`） + 本地总积分 `.xlsx` 数据仓储
- 平台：Windows / macOS / Linux（打包目标 Windows 单文件 `.exe`）

---

## 快速开始

```bash
# 依赖（Python 3.10+）
pip install "flet[desktop]==0.28.3" pandas openpyxl

# 启动
python main.py

# 核心层端到端自测（50 项断言）
python tests/test_core.py

# UI 渲染冒烟自测（flet 枚举有效性 + 全部视图构造渲染）
python tests/test_ui_render.py

# 打包版启动验证（启动 exe + 像素检测错误页）
python tools/verify_packaged.py

# 生成示例数据（samples/ 目录）
python tools/make_samples.py
```

### 5 分钟上手

1. 启动后进入**欢迎页** → 输入项目名称（如 `2026秋季集训积分`）→
   选择「初始化新模板并绑定」（或关联已有总积分 `.xlsx`）→ 创建并进入项目。
2. **活动结算**：填写活动名称、主教官，增删训练/彩排卡片，填写正式活动人员与场务 →
   生成预览 → 确认落盘（主表最右侧追加活动列并同步 F 列汇总）。
3. **批量导入**：升降旗考勤（倍率单选）/ 日常训练考勤（单次分值可配）/
   部门积分（后勤 D 列、综办 E 列，单次互斥锁）。
4. **积分排名**：按届数分组排名（默认）或按总积分全局排名；负分行淡红警示。
5. **历史撤销**：查看全部生效批次；对栈顶记录「修改」（差值增量）或「撤销」（精准回滚）。

## 功能总览

### 模块一：项目生命周期与启动逻辑
- **Project Hub 欢迎页**：新建项目 / 打开项目（历史项目列表 + 浏览 `.ghd.json`）。
- **一对一排他绑定**：工程文件强绑定唯一 Excel 路径并记录文件特征签名（路径哈希+大小+修改时间）。
- **占用检测（Lock System）**：打开项目时在 Excel 同级建立轻量锁标志 `.~[filename].lock`；
  检测到第三方 Office 属主文件 `~$xxx.xlsx` 或本软件锁标志时立即阻断：
  “目标表格已被占用，请先释放占用或关闭对应文件”，严禁并发写入。

### 模块二：数据架构与持久化
- **工程配置文件 `.ghd.json`**：元数据（项目名/创建/更新/Excel 绝对路径与签名）、
  `state`（部门单次互斥锁）、`history`（流水事务日志：Batch ID、时间戳、类型、
  变动明细 `{队员: 分值变化}`、撤销状态）。
- **总 Excel 表格**：A 姓名 / B 夜训周训 / C 升降旗 / D 后勤部 / E 综办部 / F 汇总 /
  G 起活动动态列。一切修改遵循 **预读 → 内存结算 → 预览确认 → 原子写回（含备份）**。

### 模块三：主工作台
顶部导航四入口：**积分排名** / **活动结算** / **批量导入** / **历史撤销**；
部门导入锁定后顶部常驻锁状态条。

### 模块四：活动积分结算引擎
- 动态卡片：训练卡片（N ≥ 0，可全部删空）、彩排卡片（M ≥ 1，仅剩 1 张禁删）、
  正式活动卡片（单例固定）。时长 0.5~4.0 小时、步长 0.5。
- 分隔符清洗器：`，` `,` `、` 半角/全角空格 换行；自动去空、单卡去重。
- 花名册比对：人名不在 A 列名单库时黄色预警，提供【忽略该人员】/【修正为人名库队员】。
- 计分法则：主教官每位 **+2.0**；训练/彩排/正式出旗按 **1 小时 = 1.0 分**；
  场务固定 **+0.5**；同一队员全环节线性累加。
- 落盘：主表最右侧追加活动列（列名 = 活动名称），单人分值填入对应行，
  F 列汇总实时同步（空按 0 累计）。

### 模块五：升降旗考勤导入
- 严格列名匹配 `姓名` / `总次数`；姓名空行过滤、次数 NaN → 0。
- 解析成功后**强制选择倍率**：日常升降旗 0.5 分/次 / 节假日升降旗 1.0 分/次。
- 预确认表（姓名/总次数/类型/本次加分）；不在主库的姓名整行标黄，
  支持【忽略】或【映射到主库姓名】。
- 增量写入 **C 列 + F 列**（空值安全回退，严禁 NaN）；提交后打包为原子事务，
  并提示：“若不慎导入重复文件，请前往【历史记录】模块一键撤销本批次操作”。

### 模块六：日常训练考勤导入
- 严格列名匹配 `姓名` / `总次数`；单次训练分值全局可配（默认 1 次 = 1 分）。
- 增量写入 **B 列 + F 列**；带 Batch ID 的原子事务，支持一键撤销回滚。

### 模块七：部门积分导入
- **智能夹心提取**：首列严格匹配 `姓名`、尾列严格匹配 `总积分`，中间 0~N 列明细自动忽略。
- **单次互斥锁**：`is_logistics_imported` / `is_comprehensive_imported`；
  成功落盘后对应入口立即变灰锁定，撤销后重新点亮。
- 等效单次累加：总积分 → **D 列（后勤）/ E 列（综办）+ F 列**。

### 模块八：积分排名与看板中心
- **只读内存渲染**：一切排序/过滤/高亮只在内存与 UI 层进行，
  **绝不写回原 Excel**，物理行排版（按届别依次排列）永久保持。
- **届别状态机**：A 列匹配 `^--(\d+)届--$` 更新当前届数状态，隐式为后续队员打 `generation` 标。
- 双模排序：**按届数分组排名**（届数降序 → 同届内总分降序，UI 插入届别分割线）
  / **按总积分全局排名**。负分行浅红底色加粗预警；同名姓名红色高亮防范错加。
- **活动列双显示**：可切换「活动分列」（每个大型活动独立一列，与主表 G+ 列一一对应）
  /「活动合并」（所有活动合计为一列「活动」）。
- **表格视口**：横向滚动条常驻表格区底部（随时可拖动，无需先滚到底）；
  纵向滚动条由自制滑块钉在表格区右缘（时刻可见、可拖动，滚轮滚动亦可用）；
  序号/姓名列宽收紧（32px/92px）保持美观。
- **汇总列自动重算**：F 列 = B~E 列 + 全部活动列之和，每次导入/修改/撤销后自动重算，
  保证汇总永远等于前面各列之和。

### 模块九：历史记录与撤销/修改中心
- 列表：操作时间 / 操作类型 / 涉及人数 / 操作对象 / 状态（活跃·锁定·已撤销）+ 批次详情。
- **线性版本栈**：同一操作对象的全部记录构成栈，仅栈顶【活跃】可修改/可撤销，
  其余自动【锁定】；栈顶被撤销后上一级自动解锁。
- **操作 A 部分修改**：回填该批次所有成员当时积分，提交时计算差值
  `Delta = 新 − 旧`，在活动列 + F 列增量累加，并追加全新修改记录（原记录锁定）。
- **操作 B 撤销**：初次创建 → F 列精准扣除 + 物理删除活动整列 + 释放部门锁；
  修改记录 → 按差值反向扣减恢复上一版本。

### 补充技术规约
| 规约 | 实现 |
|---|---|
| PyInstaller 静态资源隔离 | `ghd.utils.resource_path()` 基于 `sys._MEIPASS` 解析，图片/模板必须经由它 |
| 写入防崩溃 | `openpyxl.save` / `os.replace` 全部包裹 try-except；`PermissionError` 弹 Snackbar“写入失败：目标 Excel 正被其他软件占用，请关闭后重试”，绝不闪退 |
| 滚动备份 | Excel 同级隐藏 `.backups/`，落盘前拷贝 `YYYYMMDD_HHMMSS_文件名.xlsx`，自动清理仅保留最新 20 份 |
| 同名队员 | 花名册同名检测 + 预览列表红色（`colors.ERROR`）高亮，写入时仅落到首个同名行 |
| 空值安全 | 全链路 `to_num()` 防御性转换，NaN/None 一律按 0 运算，严禁写 NaN |

## 打包为单文件 .exe（PyInstaller）

```bash
pyinstaller --noconsole --onefile --name GHD-Score ^
  --add-data "resources;resources" ^
  --add-data "<site-packages>/flet_desktop/app;flet_desktop/app" ^
  --runtime-tmpdir . ^
  --hidden-import flet_core --hidden-import flet_runtime ^
  main.py
```

或直接使用仓库内配置：

```bash
pyinstaller GHD-Score.spec
```

产物位于 `dist/GHD-Score.exe`。说明：

- `--add-data "resources;resources"` 会把静态资源随包打入，
  代码通过 `resource_path("resources/...")` 读取（`sys._MEIPASS` 解压目录）。
- **flet 桌面客户端**：flet 0.28.3 的 Flutter 客户端位于
  `flet_desktop/app/`（约 94MB），运行时按 `flet_desktop.__file__` 同级
  `app` 目录查找 `flet.exe`。`GHD-Score.spec` 已将该目录作为数据文件打入包内；
  若手写命令行打包，务必附加
  `--add-data "<site-packages>/flet_desktop/app;flet_desktop/app"`，否则启动报错。
- **`runtime_tmpdir="."`**：onefile 引导器默认向 `%TEMP%` 解压；
  在受限环境（组策略/沙箱禁用用户 TEMP 写入）会报
  `Could not create temporary directory!`。spec 已将其设为 exe 同目录，
  首次启动时会在 exe 旁边生成 `_MEIxxxxxx` 临时目录，退出后自动清理。
  注意：窗口被**强制结束**（任务管理器强杀/崩溃）时会跳过清理而残留
  （每个约 160MB）。残留属可安全删除的垃圾文件，运行
  `python tools/cleanup_mei.py` 可安全清理（自动跳过运行中实例）。
- **退出行为（看门狗）**：不拦截系统原生 ✕ 关窗（本版本 flet 桌面端
  `prevent_close=True` 会导致窗口永远无法程序化关闭，卡顿约 15 秒）；
  改用看门狗线程每 0.2 秒监测窗口，窗口一消失立即释放占用锁并结束进程
  （实测窗口 0.1 秒消失、进程 3.6 秒内全部退出，无卡顿）。
  数据在每次操作时已原子落盘，快速退出不丢数据。
- 打包前请确认已安装 `pyinstaller`：`pip install pyinstaller`。
- 如遇杀毒软件误报，属 PyInstaller 单文件常见现象，可添加信任或改用 `--onedir`。

```
│   ├── name_parser.py       #   名单分隔符清洗器
│   ├── roster.py            #   花名册解析(届别状态机/同名检测)

│   ├── scoring.py           #   活动积分结算引擎(纯计算)
│   ├── import_parsers.py    #   三类导入数据契约解析
│   ├── project.py           #   工程配置持久化/事务日志/锁系统
│   ├── history_ops.py       #   批次落盘/修改/撤销 双向原子操作
│   └── recent.py            #   历史项目列表
├── app/                     # UI 层(Flet Material 3 深色主题)
│   ├── theme.py / widgets.py
│   ├── hub.py               #   Project Hub 欢迎页
│   ├── workspace.py         #   主工作台骨架(四大导航)
│   ├── dashboard.py         #   积分排名与看板中心
│   ├── event_engine.py      #   活动积分结算引擎
│   ├── import_engine.py     #   批量考勤与部门分导入引擎
│   └── history_view.py      #   历史流水与撤销中心
├── tests/test_core.py       # 核心层端到端自测(50 项断言)
├── tools/make_samples.py    # 示例数据生成
└── samples/                 # 标准模板与外部导入示例表
```
